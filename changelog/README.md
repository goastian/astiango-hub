# Historial upstream

Los archivos de este directorio conservan las notas de versiones históricas del proyecto Crawlab para trazabilidad. No describen releases de AstianGO Hub y sus nombres, enlaces y referencias se mantienen como datos históricos.

Las releases propias de AstianGO Hub deben documentarse en archivos nuevos y usar exclusivamente la versión, marca, repositorio e imágenes del fork.
